# PHASE 09 — Reviews + WhatsApp Testimonials

## Objective
Build two accurately labeled social-proof systems without customer accounts.

## Site review flow
1. Customer visits review entry.
2. Enters order number + checkout phone.
3. Server validates order ownership/match.
4. Only delivered order items are eligible by default.
5. Customer selects product/order item.
6. Rating 1–5.
7. Comment.
8. Optional image.
9. Prevent duplicate reviews for the same order item.
10. Save as pending moderation.
11. Admin approves/rejects.
12. Approved verified reviews show appropriate verified-purchase label.

## WhatsApp testimonials
Admin-only management of customer screenshots:
- upload screenshot/image
- optional display name
- optional city
- optional caption
- optional product association
- publish/hide
- sort order

Unapproved screenshot media should not be publicly exposed.

## Privacy check
Before publishing a WhatsApp screenshot, require admin confirmation that visible phone numbers, addresses, and unrelated private content have been reviewed. Do not claim a WhatsApp screenshot is a native site review.

## Definition of Done
Both systems are functional, moderated, accurately labeled, and do not require customer accounts.
