# PHASE 11 — SEO + Performance + Accessibility

## Objective
Make the complete site discoverable, fast, stable, and accessible.

## SEO tasks
- per-route metadata
- Arabic titles/descriptions
- canonical URLs
- robots.txt
- sitemap.xml
- Open Graph
- Product/ProductGroup structured data for variants
- accurate availability and pricing
- semantic headings
- no accidental indexing of combinatorial filter URLs

## Performance tasks
- responsive optimized images
- appropriate image priority for LCP hero/product content
- minimal client JS
- server-first rendering where appropriate
- cache/revalidate data intentionally
- avoid layout shift
- avoid oversized fonts/images

Targets at 75th percentile, segmented by mobile/desktop:
- LCP <= 2.5s
- INP <= 200ms
- CLS <= 0.1

## Accessibility tasks
Target WCAG 2.2 AA:
- labels
- keyboard navigation
- visible focus
- semantic landmarks
- accessible dialogs
- color contrast
- touch target review
- reduced motion
- form error association

## Definition of Done
Lighthouse/automated accessibility checks and manual keyboard/phone checks are completed, with all material defects fixed or formally documented.
