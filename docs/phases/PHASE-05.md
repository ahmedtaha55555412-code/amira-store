# PHASE 05 — Storefront Navigation + Search + Filters + Product Pages

## Objective
Turn the catalog into a production-grade Arabic storefront.

## Tasks
1. Build header/navigation responsive for phone/tablet/desktop.
2. Build simple category navigation and breadcrumbs.
3. Build category listing page.
4. Build product cards with sale/out-of-stock/wishlist states.
5. Build search UI with autocomplete.
6. Build Arabic-aware search service.
7. Search fields: product name, SKU, description, category names, attribute values.
8. Support exact/prefix/fuzzy matching where practical.
9. Implement category-aware dynamic filters.
10. Implement sorting.
11. Build product detail page with:
   - gallery
   - price block
   - original price
   - discount
   - variant selectors
   - dynamic availability
   - quantity
   - add-to-cart entry point
   - wishlist
   - description/details
   - optional size guide
   - reviews
12. Ensure selected variant is explicit and is carried to cart.
13. Use structured data-ready product metadata contracts.

## UX states
- loading
- empty category
- no search results
- search error
- out of stock
- inactive variant
- long Arabic titles

## Definition of Done
A customer can discover a product from homepage/category/search, understand its actual variant/price/stock, and prepare to add it to cart.
