# Phase Prompt Template

Use one phase prompt at a time.

> Read `AGENTS.md`, `MASTER_PLAN.md`, and `EXECUTION_STATUS.md` first. Then read only the phase file for the current phase. Implement ONLY that phase. Do not start later phases. Before coding, inspect the existing repository and preserve valid work. After implementation, run the phase tests/checks, fix all issues using `docs/ops/ERROR_PROTOCOL.md`, update `docs/qa/TRACEABILITY.md`, update `EXECUTION_STATUS.md`, commit the phase, report the exact result, and STOP.

## Phase selection
Replace `PHASE_XX` with the exact value in `EXECUTION_STATUS.md`.

## Required agent response
- Phase:
- Status: PASS / BLOCKED
- Files changed:
- Commands/checks executed:
- Tests passed:
- Issues fixed:
- Issues remaining:
- Commit:
- Next phase set to:

Never claim PASS with failing tests/checks.
